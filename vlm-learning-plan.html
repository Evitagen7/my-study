二、知识体系：六层知识地图

每层都有动手验收标准，避免停留在"懂概念"。L5（VLM 核心）是主战场；L6 在冲刺期只做概念了解，实操推迟到缓冲期。

L0
工具链
Python、PyTorch、Linux、Git、LeetCode 入门
验收：独立训练一个 CNN 分类器；LeetCode 累计 100 题
L1
深度学习基础
反向传播、优化器（SGD/Adam）、损失函数、CNN（卷积/池化/BN）、正则化与过拟合
验收：手写 MLP/CNN；能根据训练曲线定位并修复过拟合
L2
Transformer
Attention（Q/K/V、缩放点积）、Multi-Head、位置编码（绝对/RoPE）、Decoder-only、KV Cache
验收：复现 nanoGPT，训练出能生成文本的小模型
L3
大语言模型
Tokenizer（BPE）、预训练目标、SFT、RLHF/DPO、LoRA/QLoRA、上下文学习
验收：用 LoRA 微调开源 LLM 到垂直任务并做对比实验
L4
视觉与图文对齐
ViT（patch、CLS token）、CNN 骨干、CLIP 对比学习（图文对、InfoNCE）、图文检索
验收：用 CLIP 搭建图文检索 demo，讲清对比学习原理
L5
VLM 核心
三件套架构（视觉编码器+投影器+LLM）；LLaVA 两阶段训练；模型谱系；幻觉与缓解；多模态评测
验收：复现/微调 LLaVA 或 Qwen-VL，完成一个垂直任务项目
L6
进阶与工程
多模态 SFT/RLHF/DPO、视频理解、多模态 Agent、高效推理（vLLM/LMDeploy/量化）、分布式训练（DeepSpeed/FSDP）
验收（缓冲期）：用 vLLM 部署多模态模型；做一个多模态 Agent demo

三、大厂 VLM 岗位：五类岗位对比

同一家公司内部，"研究院/实验室"偏研究，业务团队偏工程应用，平台组偏系统。投递前看 JD 关键词："论文优先/探索新方法"是研究向，"业务落地/数据工程/上线"是工程向。

岗位类型典型工作内容硬门槛适合谁
研究型 新方法探索、前沿论文复现、对比实验、发 paper 顶会论文优先；数学/理论扎实；通常博士或科研强硕士有学术追求、实验室资源好
工程/应用型 模型训练调优、数据工程、业务落地（电商图文理解、搜索、内容审核） PyTorch 工程能力、数据意识、能独立跑通训练流程大多数硕士，岗位最多，主攻方向
系统/推理优化 vLLM/TensorRT-LLM 部署、量化、分布式训练（Megatron/DeepSpeed） C++/CUDA、系统知识、性能调优系统方向、对性能敏感
评测/数据 评测体系建设、数据集构建、badcase 分析、自动化评估 细心、脚本强、理解模型能力边界入门友好，适合第一段实习
Agent/应用 多模态 Agent、工具调用、GUI Agent、RAG 应用开发 产品感、快速开发、熟悉主流 Agent 框架对应用和产品感兴趣

五、冲刺期每周节奏与调整规则

冲刺期每周节奏

  • 代码实操 ≥ 30 小时（每天 4-5 小时，周末 8 小时攻坚）
  • 论文/博客精读 3-5 篇，每篇写 200 字总结
  • LeetCode 每日 1-2 题（Hot100 为主线）
  • 每 3-4 天一个小里程碑：demo / 核心论文 / 实验对比
  • 每周复盘：写下本周能"讲给面试官听"的 3 个知识点

调整规则

  • 每周未达标 → 周末补短板，压缩下一周非核心内容
  • 不可压缩项：nanoGPT 复现、VLM 微调项目、Hot100 两遍
  • 可推迟项：L6 进阶、开源 PR、更多论文精读 → 缓冲期
  • 面试提前到来 → 切换"项目深挖 + Hot100 + 八股"三件套
  • 算力不足 → Colab / 国内算力平台 / 换更小模型（4B/2B 级）
2 个月冲刺的取舍：这是把常规 6-9 个月规划压到 8 周的加速版，要求每周 35-40 小时且一次到位；如果某周验收反复不过，就压缩外围内容保核心，不要硬跳基础。若 12 月中仍未达到 W8 标准，最差情况是把正式投递推迟到研一日常实习，损失可控。

六、第 1-2 周行动清单（冲刺版）

  • 装环境：Python 3.10+、Anaconda、PyTorch 2.x、VS Code、Git；注册 GitHub
  • 跑完 PyTorch 官方 60 分钟教程，训练第一个 MNIST 分类器
  • LeetCode Hot100 开始：第 1-2 周完成数组/哈希/双指针 30 题（节奏加倍）
  • 读《The Illustrated Transformer》+ 李沐 Transformer 论文精读，写 300 字理解
  • 建学习仓库：README 写 2 个月规划，每天提交学习日志
  • 确认算力来源：本地 GPU / Colab / 校园卡 / 租卡平台
  • 第 2 周结束自查：能否独立写完并训练一个分类模型？能，进入 W3；不能，用周末补齐
